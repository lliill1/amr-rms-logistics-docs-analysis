# Оценка качества извлечения

Сюда кладётся эталонная разметка: требования, выписанные аналитиком вручную из 5–10 разнотипных документов. По ней сравнивается результат модели (точность и полнота), прежде чем менять модель или промпт.

Сами документы заказчика сюда не кладите — только ссылки на них (путь в архиве) и выписанные требования, например в `requirements_gold.csv`:

```
doc_rel_path;page;requirement;target
02_EWM/ПР_EWM_v2.3.docx;34;RMS принимает транспортные задания от EWM;RMS
```

Запуск:

```
python scripts\eval_requirements.py eval\requirements_gold.csv --details
```

Скрипт покажет точность (какая доля найденного моделью есть в эталоне), полноту (какая доля эталона найдена)
и списки пропущенного и лишнего. Образец для вымышленного демо-архива — `requirements_gold.example.csv`.
